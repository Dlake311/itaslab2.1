# Лабораторная работа 2, часть 1 — StringBuffer: обратный порядок и добавление строк

Консольное приложение на Java с интерактивным меню и хранением результатов в PostgreSQL.

## Пункты меню

1. Вывести все таблицы из PostgreSQL
2. Создать таблицу в PostgreSQL
3. Изменить порядок символов строки на обратный (`StringBuffer.reverse()`)
4. Добавить одну строку в другую (`append()` / `insert()`)
5. Сохранить все данные из PostgreSQL в Excel и вывести на экран

Перед пунктами 3–4 программа показывает ранее введённые строки (не менее 50 символов) и предлагает ввести новые.

## Что нужно для запуска

- JDK 17 или новее (проект настроен на JDK 25).
- PostgreSQL на `localhost:5432`, база `postgres`, пользователь `postgres`, пароль `postgres`.
  Если у вас другие данные, поменяйте константы `URL`, `USER`, `PASSWORD` в начале класса `Laba` в `src/Main.java`.
- Драйвер PostgreSQL JDBC уже лежит в папке `lib/` и подключён к проекту.

## Запуск

**IntelliJ IDEA:** File → Open → папка проекта → `src/Main.java` → Run.

**Командная строка (Windows):**
```
javac -encoding UTF-8 -d out src/*.java
java -cp "out;lib/postgresql-42.7.10.jar" Main
```
(на Linux/macOS в `-cp` вместо `;` ставится `:`)

## Порядок работы

1. Пункт **2** — ввести имя таблицы (латиница, цифры, `_`). Таблица создаётся, если её нет, и выбирается для работы.
2. Выполнить нужные пункты — результаты сохраняются в таблицу и выводятся в консоль, прочитанные из БД.
3. Последний пункт — выгрузка в `<имя_таблицы>.csv` на Рабочий стол (если его нет — в папку проекта), вывод в консоль и открытие файла в Excel. Файл в UTF-8 с BOM и разделителем `;`, поэтому русский текст в Excel отображается правильно.
